# 📁 File Uploader API

A Spring Boot application that allows users to register, upload files, and receive email notifications. Uploaded files are processed asynchronously using RabbitMQ and stored in AWS S3. PostgreSQL is used as the main database.

---

##  Features

- ✅ User registration and login
- ✅ File upload with validation
- ✅ Asynchronous processing via RabbitMQ
- ✅ Secure storage in AWS S3
- ✅ Email notifications (e.g., upload success, password reset)
- ✅ PostgreSQL integration
- ✅ Dockerized setup for local development

---

##  Tech Stack

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- Spring Mail
- RabbitMQ
- AWS S3 SDK v2
- PostgreSQL
- Docker & Docker Compose
